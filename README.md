One short funny line for the make.fun bounty "One-Liner Laugh Lab": the excuse a robot vacuum gives after eating a sock.

> "The sock attacked first. I have the sensor logs to prove it."

Run `node main.ts` and it writes the line to `/output/entry.txt` (60 code points, within the 200-character limit).
